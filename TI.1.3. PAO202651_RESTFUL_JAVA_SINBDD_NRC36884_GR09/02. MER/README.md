# 02. MER — Modelo Entidad-Relación

Esta carpeta se mantiene sin modelos ni diagramas de base de datos debido a que este proyecto corresponde estrictamente a la modalidad **SINBDD (Sin Base de Datos)**.

### Justificación Técnica:
- **Sin Persistencia:** No existe base de datos relacional ni motor de almacenamiento externo.
- **Autenticación en Memoria:** Las credenciales requeridas para el acceso al sistema están definidas directamente en el código (MONSTER / MONSTER9).
- **Conversiones:** Las fórmulas y los factores de conversión de unidades se calculan en memoria en la capa del servicio web.
