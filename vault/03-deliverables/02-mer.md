# 02 · MER

Carpeta `02. MER/` de cada variante.

> [!danger] La carpeta queda vacía
> El proyecto es **SINBDD** (sin base de datos). No hay modelo entidad-relación real, por
> lo que `02. MER/` permanece **vacía** en las cuatro variantes. No genera scripts SQL,
> migraciones ni ORM.

## Qué deja el scaffold

`02. MER/` solo contiene su archivo `.gitkeep` (para que git conserve la carpeta vacía).
**No lo borres.**

En el ejemplo de referencia (`examples/`) esta carpeta incluye subcarpetas
`01. CONCEPTUAL/`, `02. LOGICO/` y `03. FISICO/` con `README.txt` de relleno; **en este
repositorio no se crean** porque no aplican.
