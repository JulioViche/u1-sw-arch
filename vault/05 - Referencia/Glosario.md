# Glosario

| Término | Significado |
| --- | --- |
| **ERS** | Especificación de Requisitos de Software. |
| **ECUD** | Especificación de Casos de Uso Detallados. |
| **MER** | Modelo Entidad-Relación. En este proyecto la carpeta queda vacía (SINBDD). |
| **SINBDD** | Variante **sin base de datos**: datos fijos o en memoria. |
| **Login** | Autenticación obligatoria al iniciar; credenciales quemadas `MONSTER` / `MONSTER9`. |
| **RESTful** | Estilo arquitectónico basado en recursos y verbos HTTP. |
| **SOAP** | Protocolo de mensajería XML con contrato WSDL. |
| **JAX-RS / JAX-WS** | APIs Java para servicios REST / SOAP. |
| **WSDL** | Contrato de un servicio SOAP. |
| **WCF / ASMX** | Tecnologías .NET para servicios. |
| **CLICON/CLIESC/CLIWEB/CLIMOV** | Clientes de consola, escritorio, web y móvil. |
| **MOC** | *Map of Content*: nota índice en Obsidian. |
| **Vault** | Carpeta raíz de una bóveda de Obsidian. |
